## Evidência
Máquina: Windows 11, MinGW g++ (WinLibs), Debug, 2026-10-27. Dados sintéticos (não são assets reais).

```
$ ctest --test-dir build -R sw-pack --output-on-failure
  sw-pack-codec ... Passed; sw-pack-chunker ... Passed; 100% tests passed out of 2

$ build/sw-pack/sw-pack-report.exe <amostra> --codec auto
tipo             codec    arqs  blocos       bruto(B)      empac.(B)    taxa  comp MB/s  desc MB/s
json             zstd        1      12        1870005         118991    6.4%       16.2       52.8
mesh             lz4         1       7         960000         507881   52.9%       40.7      244.0
png              none        1       4         600000         600000  100.0%     1229.8     2116.1
tscn             zstd        1      10        1277780          32555    2.5%       35.7       78.3
wav              lz4         1       4         500000          34223    6.8%      116.4      997.6
...
```
Com `--codec zstd` o `.mesh` sintético vira 13,1% (contra 52,9% no LZ4) a 47,8 MB/s de descompressão (contra 244): a tabela de extensões é só um ponto de partida e deve ser calibrada com os assets reais (fora deste PR). Os números de velocidade são de uma rodada, sem a máquina isolada: não são benchmark.
